# ～てくれ {#てくれ}
#japanese-grammar
#grammar

**1. Kanji version:** ～て呉れ (archaic kanji form; almost always written in hiragana as てくれ)

**2. Furigana version:** ～てくれ

**3. Meaning:** (Please) do X for me — a blunt, masculine imperative request.

**4. Conjugation (connection form):** 動詞て形 + くれ

**5. Usage context:** Spoken only; casual/blunt, typically masculine speech. Common in fiction dialogue, commands between close friends or family, or orders from a superior to a subordinate. Can sound rude if used toward someone of higher status.

**6. Similar grammar structures:**
- てみろ — a challenge/dare ("try doing X"), not a request for help. Confirmed as the tested distractor that beat out てみろ in the source student's wrong answer on the same question.
- てください — the polite equivalent request form, appropriate in formal/neutral contexts.
- てくれる — the plain (non-imperative) benefactive verb form, "to do something for me," used in ordinary sentences rather than as a command.

**7. Opposite grammar structures:** てくださいませんか (a very polite request) is the polite-register opposite.

**8. Example sentences:**
1. ちょっと待ってくれ。(Wait a moment for me.)
2. 山下君、すまないが、この資料を10部コピーしてくれ。(Yamashita, sorry to ask, but please copy this document ten times for me.)
3. 頼むから、静かにしてくれ。(I'm begging you, please be quiet.)
4. これを運ぶのを手伝ってくれ。(Help me carry this.)
5. 俺のことは心配しないでくれ。(Don't worry about me.)

**9. Common mistakes / key nuances:** Source data confirms てくれ was the distractor that beat out てみろ in a student's wrong answer on Q7 — remember てくれ asks someone to do something FOR the speaker (a request), while てみろ dares or challenges someone to attempt an action themselves. Also note てくれ's bluntness makes it inappropriate toward superiors without added politeness markers.
