# ～てたまらない／～て仕方がない／～てしょうがない {#てたまらないてしようがないてしかたがない}
#japanese-grammar
#grammar

**Kanji form:** ～てたまらない／～て仕方がない／～てしょうがない

**Furigana form:** ～てたまらない／～てしかたがない／～てしょうがない

**Meaning:** "Unbearably X, cannot help feeling X" — intensifies an emotion or physical sensation to the point of being unbearable or uncontrollable.

**Conjugation:**
- い形容詞 (くて) + たまらない／しかたがない／しょうがない
- な形容詞 (で) + たまらない／しかたがない／しょうがない
- 動詞たい形 (たくて) + たまらない／しかたがない／しょうがない

**Typical context:** Spoken, casual-to-neutral; しょうがない is more casual than しかたがない, and たまらない is slightly more emphatic/literary.

**Similar grammar structures:**
- [**てならない**](grammar-てならない.md) — more literary/written equivalent with the same meaning, slightly more formal in register.
- **堪えられない** — "unbearable," a more formal standalone expression.

**Opposite grammar structures:** No direct opposite, though 平気だ ("unfazed, unbothered") contrasts in spirit.

**Example sentences:**
1. 久しぶりに家族に会えて、嬉しくてたまらない。
   (I'm unbearably happy to see my family after so long.)
2. 試験の結果が気になって仕方がない。
   (I can't help worrying about the exam results.)
3. 疲れていて、眠くてしょうがない。
   (I'm so tired I can't help feeling sleepy.)
4. 彼のことが心配でたまらない。
   (I can't help being worried about him.)
5. 新しいゲームがしたくてしょうがない。
   (I'm dying to play the new game.)

**Common mistakes / key nuances:** These expressions attach to emotion/sensation-related adjectives or the たい-form, not directly to plain action verbs. しかたがない／しょうがない also have a separate, very common meaning ("it can't be helped / nothing can be done about it"), which learners often confuse with this emphatic-emotion usage.
