# ～てみろ {#てみろ}
#japanese-grammar
#grammar

**1. Kanji version:** ～て見ろ

**2. Furigana version:** ～てみろ

**3. Meaning:** Try doing X / go ahead and do X — an imperative challenge or dare directed at the listener.

**4. Conjugation (connection form):** 動詞て形 + みろ

**5. Usage context:** Spoken only; masculine, blunt, casual-to-rude register. This is a command form and is never appropriate in polite or formal writing/speech.

**6. Similar grammar structures:**
- てみせる — expresses the SPEAKER's own determination/proof ("I will do X, you'll see"), not a command directed at someone else. Confirmed confusion: student picked てくれ instead of てみろ on a related question.
- てくれ — a blunt imperative REQUEST ("do X for me"), different intent from てみろ's challenge/dare. Confirmed as the actual distractor that beat out てみろ in a student's wrong answer.
- てみて — the polite/neutral equivalent, "please try doing X," much softer than てみろ.

**7. Opposite grammar structures:** てみてください (the polite request version) functions as the polite counterpart.

**8. Example sentences:**
1. 部長の前でそんなこと言ってみろ、3時間は説教されるぞ。(Just try saying that in front of the department head — you'll get a three-hour lecture.)
2. 文句があるなら、自分でやってみろ。(If you have complaints, then try doing it yourself.)
3. そんなに自信があるなら、一人でやってみろよ。(If you're so confident, then go ahead and do it alone.)
4. できるものなら、やってみろ。(If you think you can do it, go ahead and try.)
5. もう一度言ってみろ、ただじゃおかないぞ。(Say that again, and you won't get away with it.)

**9. Common mistakes / key nuances:** Confirmed student confusion between てみろ and てくれ. The key distinction: てみろ is a challenge/dare meaning "go ahead, try it" (often confrontational), whereas てくれ is a direct request meaning "do this for me." Both are blunt imperative forms, but their social function is opposite — one challenges, the other asks for help.
