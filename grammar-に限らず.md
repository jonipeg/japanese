# ～に限らず {#に限らず}
#japanese-grammar
#grammar

**Kanji form:** ～に限らず

**Furigana form:** ～にかぎらず

**Meaning:** "Not limited to ~ / not only ~ (but also)" — indicates that a statement applies beyond the specific item mentioned, extending to a broader category.

**Conjugation:**
- 名詞 + に限らず — 例: 日本に限らず (not only in Japan)

**Typical context:** Both written and spoken, neutral-to-formal — common in essays, news articles, and discussions making a generalizing point.

**Similar grammar structures:**
- **だけでなく** — "not only ~ but also," very similar meaning, slightly more common/neutral in everyday use.
- [**のみならず**](grammar-のみならず.md) — more formal/literary equivalent, used in writing and speeches.
- [**に限って**](grammar-に限って.md) — opposite flavor; restricts to one specific (often ironic) case rather than broadening scope.

**Opposite grammar structures:** **に限り/に限って** (restricting to only one case) contrasts with に限らず's broadening function.

**Example sentences:**
1. この問題は日本に限らず、世界中で起きている。
   (This problem is occurring not only in Japan but around the world.)
2. 若者に限らず、高齢者もスマートフォンを使うようになった。
   (Not only young people, but elderly people too have come to use smartphones.)
3. 休日に限らず、平日もこの店は混んでいる。
   (This shop is crowded not only on holidays but on weekdays too.)
4. この薬は風邪に限らず、様々な症状に効果がある。
   (This medicine is effective not only for colds but for various symptoms.)
5. 都市部に限らず、地方でも人手不足が深刻化している。
   (Labor shortages are becoming serious not only in urban areas but in rural areas as well.)

**Common mistakes / key nuances:** Learners sometimes confuse に限らず with に限って because both contain 限る, but they are near-opposites in function — に限らず broadens scope while に限って narrows it to one ironic instance.
