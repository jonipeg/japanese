# ～きる {#きる}
#japanese-grammar
#grammar

**Kanji form:** ～きる（切る）

**Furigana form:** ～きる

**Meaning:** "To do completely / to the end / fully" — attached to a verb stem to emphasize completion or an extreme degree of the action.

**Conjugation:**
- 動詞ます形（stem）+ きる
- 食べきる — "eat all of it"
- 疲れきる — "be utterly exhausted"
- 使いきる — "use up completely"
- 言い切る — "state assertively/definitively"

**Typical context:** Spoken and written, neutral register — very common in daily conversation.

**Similar grammar structures:**
- **尽くす** — "to do to the utmost / exhaust," a similar completion nuance but more formal/literary, often referring to effort or resources.
- **終える／終わる** — plain "to finish," a neutral completion without きる's "to the fullest extent" emphasis.

**Opposite grammar structures:** No single direct opposite, though ～かける ("to start / be in the middle of doing") contrasts as an incomplete action.

**Example sentences:**
1. 出された料理を全部食べきった。
   (I ate everything that was served.)
2. 一日中働いて、疲れきってしまった。
   (I worked all day and became utterly exhausted.)
3. 持っていたお金を使いきってしまった。
   (I used up all the money I had.)
4. 彼は自分の意見を最後まで言い切った。
   (He stated his opinion firmly to the end.)
5. そのマラソンを無事に走りきった。
   (I managed to run the whole marathon to the finish.)

**Common mistakes / key nuances:** きる sometimes shifts to an idiomatic meaning (言い切る = assert confidently, 疲れきる = totally exhausted) rather than a purely literal "finish doing" — it's best to learn common set combinations rather than assume a purely compositional meaning each time.
