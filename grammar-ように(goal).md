# ～ように（目的）{#ように-goal}
#japanese-grammar
#grammar

**Kanji form:** ～ように

**Furigana form:** ～ように

**Meaning:** "So that..., in order to..." — expresses a purpose or goal, typically used with potential-form verbs or non-volitional verbs (unlike ため which requires volitional verbs).

**Conjugation:**
- 動詞辞書形/ない形 (dictionary or nai-form, often potential) + ように: 忘れないように書いておく (I'll write it down so I won't forget)
- 動詞可能形 + ように: 誰にでも分かるように説明する (explain so that anyone can understand)
- Often used with imperative-adjacent sentences: 風邪をひかないように気をつけてください (please be careful so you don't catch a cold)

**Typical context:** Spoken and written, neutral-to-polite register. Extremely common in instructions, advice, and wishes for an outcome, especially with non-volitional verbs (できる, 分かる, 治る, 間に合う) or negative forms.

**Similar grammar structures:**
- **ため(に)** — also means "in order to," but requires a volitional verb and the subject must have control/intention; ように is used instead when the verb is non-volitional or potential.
- **のに** — used for "in order to" with a slightly different nuance, often about usage/means (このはさみは紙を切るのに使う).
- **ように願う/祈る** — fixed collocations expressing hopes ("I hope/pray that...").

**Opposite grammar structures:** No direct opposite.

**Example sentences:**
1. 遅刻しないように、早めに家を出た。
   (I left home early so that I wouldn't be late.)
2. 子供にも分かるように、簡単な言葉で説明した。
   (I explained using simple words so that even children could understand.)
3. 風邪が早く治るように、ゆっくり休んでください。
   (Please rest well so that your cold heals quickly.)
4. 試験に合格できるように、毎日勉強している。
   (I study every day so that I can pass the exam.)
5. 皆さんに聞こえるように、もう少し大きな声で話してください。
   (Please speak a bit louder so that everyone can hear you.)

**Common mistakes / key nuances:** The key nuance is the volitional/non-volitional distinction with ため: use ため(に) when the subject intentionally acts to achieve a goal with a volitional verb (合格するために勉強する), and use ように when the verb is non-volitional, potential, or negative (合格できるように勉強する / 忘れないように). Learners often use ため where ように is required, which sounds unnatural with potential/negative verbs. Also don't confuse this purpose use with the comparison/example use of ように (see separate entry).
