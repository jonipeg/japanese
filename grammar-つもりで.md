# ～つもりで (pretend) {#つもりで}
#japanese-grammar
#grammar

**1. Kanji version:** ～積もりで (rare kanji; usually written in hiragana as つもりで)

**2. Furigana version:** ～つもりで

**3. Meaning:** With the intention of / as if pretending to X — acting as though something were done or true, often for self-discipline or framing purposes.

**4. Conjugation (connection form):** 動詞た形 + つもりで (the "pretend" nuance specifically uses た形, e.g. 買ったつもりで "as if I had bought it")

**5. Usage context:** Written and spoken, neutral register.

**6. Similar grammar structures:**
- ふりをして — "pretend to be/act as if," more literal "feign," usually about deceiving others, whereas つもりで is more about the speaker's own mental framing or self-discipline rather than deceiving someone else.
- まま(に) — confirmed confusion in source data (student wrongly picked つもり for a まま(に) question, Q5). まま(に) describes passively following along with an external circumstance, the opposite orientation from つもりで's self-directed, deliberate intention.

**7. Opposite grammar structures:** No direct opposite.

**8. Example sentences:**
1. 冬のコートを買ったつもりで、5万円貯金した。(I saved 50,000 yen, treating it as if I had bought a winter coat.)
2. 新しい自分に生まれ変わったつもりで、毎日の生活を見直してみた。(I reconsidered my daily life, as if I had been reborn as a new person.)
3. 旅行に行ったつもりで、家でゆっくり過ごすことにした。(I decided to relax at home, as if I had gone on a trip.)
4. もう一度学生に戻ったつもりで、勉強をやり直した。(I started studying again, as if I had become a student once more.)
5. タバコをやめたつもりで、そのお金を貯金に回している。(I'm putting that money into savings, acting as if I had quit smoking.)

**9. Common mistakes / key nuances:** Confirmed source data shows a student confusing つもりで with まま(に). Remember つもりで signals a deliberate, self-directed pretense or intention (the subject actively frames their own behavior "as if X"), while まま(に) describes passively following an external circumstance or another person's words/actions without the subject's own initiative.
