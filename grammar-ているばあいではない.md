# ～ているばあいではない {#ているばあいではない}
#japanese-grammar
#grammar

**Kanji form:** ～ている場合ではない

**Furigana form:** ～ているばあいではない

**Meaning:** "This is not the time for X" — urges that a current action is inappropriate or irresponsible given more pressing circumstances.

**Conjugation:**
- 動詞ている形 + 場合ではない
- Example base: 冗談を言っている → 冗談を言っている場合ではない

**Typical context:** Neutral-to-casual spoken register; conveys urgency or mild scolding, telling someone (including oneself) to stop a trivial activity and focus on something urgent.

**Similar grammar structures:**
- [**どころではない**](grammar-どころではない.md) — "it's not the time/situation for X" (e.g., 旅行どころではない); very close in meaning and often interchangeable, though どころではない can attach more broadly to nouns and plain clauses, while 場合ではない specifically follows a ~ている ongoing-action form.
- **ことではない** — a more general "it's not a matter of X," lacking 場合ではない's specific urgency about timing/priority.
- **場合じゃない** — the casual contracted form of the same pattern, used in very informal speech.

**Opposite grammar structures:** 今がチャンスだ／今こそ～すべきだ ("now is the chance / now is exactly the time to do X") expresses the reverse — that the moment is appropriate for action.

**Example sentences:**
1. 冗談を言っている場合ではありません。早く対応策を考えないと。 (This is not the time for joking. We need to think of a countermeasure quickly.)
2. こんなところで休んでいる場合ではない、早く避難しよう。 (This is not the time to be resting here — let's evacuate quickly.)
3. 迷っている場合ではない、今すぐ決断しなければ。 (This is not the time to hesitate — we must decide right now.)
4. 彼が倒れたのに、のんびりしている場合ではないだろう。 (He's collapsed — this is clearly not the time to be relaxed about it.)
5. 締め切りが明日なのに、テレビを見ている場合じゃないよ。 (The deadline is tomorrow — this is no time to be watching TV.)

**Common mistakes / key nuances:** This pattern always implies an unstated but understood urgent priority that should be addressed instead — learners should make sure context (or a following clause) clarifies what should be done instead, since 場合ではない alone only states what should NOT be happening. It's commonly used as a self-directed or group-directed call to action, akin to "snap out of it and focus," rather than a neutral observation.
