# ～きりがない {#きりがない}
#japanese-grammar
#grammar

**Kanji form:** ～切りがない

**Furigana form:** ～きりがない

**Meaning:** "There's no end/limit to X" — expresses that if one kept going, an activity, list, or complaint would never conclude.

**Conjugation:**
- 動詞辞書形（たら／と／ば形でも可） + きりがない
- 動詞ば形 + きりがない (数えればきりがない)
- Example base: 数える → 数えたらきりがない

**Typical context:** Neutral, usable in both speech and writing; common in everyday conversation to wave off an open-ended topic ("if I listed them all, there'd be no end to it").

**Similar grammar structures:**
- [**ばかりだ**](grammar-ばかりだ.md) — "all that happens is X"; describes an ongoing worsening trend, distinct from きりがない's "no natural stopping point" sense.
- **際限がない** — "there's no limit"; a more formal synonym, used in slightly more written/formal contexts than the everyday きりがない.
- **いくらでも～** — "any amount of X (is possible)"; shares the "unlimited" semantic field but frames it as abundance/possibility rather than an exhausting open-endedness.

**Opposite grammar structures:** 限りがある ("there is a limit") expresses the reverse — that something does have a defined end.

**Example sentences:**
1. 失恋したことですか？数えたらきりがないですね。 (Heartbreaks? If I started counting, there'd be no end to it.)
2. 彼の悪口を言い出したらきりがない。 (If I start listing his faults, there's no end to it.)
3. 細かいことを気にし出すとキリがないよ。 (If you start worrying about every little detail, there's no end to it.)
4. やるべきことを挙げればきりがないほどある。 (There are so many things to do that listing them all would be endless.)
5. 値引き交渉をしていてはきりがないので、この値段で決めましょう。 (Haggling over the price would go on forever, so let's settle on this price.)

**Common mistakes / key nuances:** きりがない almost always follows a conditional form (〜たら／〜と／〜ば) of the triggering verb, setting up "if you started doing X, there'd be no end" — using it as a bare statement without that conditional setup sounds incomplete. It typically conveys mild exasperation about something open-ended (complaints, examples, worries), rather than a neutral mathematical "infinite" claim.
