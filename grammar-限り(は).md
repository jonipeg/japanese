# ～限り(は) {#限り(は)}
#japanese-grammar
#grammar

**Kanji form:** ～限り(は)

**Furigana form:** ～かぎり(は)

**Meaning:** "As long as ~ (the condition holds) / so long as" — expresses that as long as a certain state or condition continues, the related result/action also holds true.

**Conjugation:**
- 動詞辞書形/ている形 + 限り(は) — 例: 生きている限り (as long as I'm alive)
- い形容詞 + 限り(は) — 例: 体が健康である限り
- 名詞＋である + 限り(は) — 例: 学生である限り

**Typical context:** Both written and spoken, neutral-to-formal register — common in speeches, promises, and serious personal statements.

**Similar grammar structures:**
- [**ない限り**](grammar-ない限り.md) — the negative counterpart, "unless" (covered separately).
- **間は** — "while," more neutral/temporal, lacks the conditional "as long as this holds" nuance.
- **うちは** — similar "while X is the case," slightly more casual.

**Opposite grammar structures:** [**ない限り**](grammar-ない限り.md) ("unless") functions as the negative mirror of this pattern.

**Example sentences:**
1. 命がある限り、諦めません。
   (As long as I'm alive, I won't give up.)
2. 規則を守っている限り、自由に行動してもいい。
   (As long as you follow the rules, you're free to act as you like.)
3. 彼が謝らない限り、私は許すつもりはない。
   (As long as he doesn't apologize, I don't intend to forgive him.) *(note: this uses ない限り, see separate card)*
4. お金が続く限り、旅行を続けるつもりだ。
   (As long as my money lasts, I intend to keep traveling.)
5. 体力が許す限り、働き続けたい。
   (As long as my physical strength allows, I want to keep working.)

**Common mistakes / key nuances:** 限り(は) emphasizes a condition that must continue to hold for the result to remain true, unlike 間 which simply marks a time period without that conditional, cause-and-effect weight — mixing the two can make a sentence sound flatter than intended.
