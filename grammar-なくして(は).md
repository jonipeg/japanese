# ～なくして(は) {#なくして(は)}
#japanese-grammar
#grammar

**Kanji form:** ～無くして(は)

**Furigana form:** ～なくして(は)

**Meaning:** "Without X, (Y would not be possible / Y cannot happen)" — a formal way of saying that something is an indispensable precondition for something else, almost always paired with a negative-potential predicate at the end (～ことはできない, ～ない, etc.).

**Conjugation:**
- [Noun] + なくして(は) + ～ない/～ことはできない
- The は is optional and adds emphasis ("without X, in particular...").
- Derives historically from the negative stem of ある (無く) + して, functioning as a formal "without" connective.

**Typical context:** Formal, written/literary register. Common in essays, speeches, and formal writing about abstract values (love, trust, effort, peace). Not used in casual conversation. Politeness-neutral but stylistically elevated — sounds bookish if used in small talk.

**Similar grammar structures:**
- [**なしに**](grammar-なしに.md) — "without doing X," more general-purpose and slightly less formal; often used for actions done "without permission/notice" (断りなしに) rather than abstract indispensable preconditions.
- **ないで** — plain, neutral "without doing X," usable in casual speech; lacks the formal, almost philosophical weight of なくして(は).
- **ずに** — formal/written "without doing," interchangeable with ないで in writing, but does not carry the specific "indispensable condition" nuance that なくして(は) implies.
- **があってこそ** — the positive mirror-image idea ("precisely because there is X"), often taught alongside なくして(は) as the affirmative counterpart.

**Opposite grammar structures:** ～があってこそ ("precisely because X exists, Y is possible") functions as a natural positive counterpart, though it is not a strict grammatical negation.

**Example sentences:**
1. 愛なくして結婚生活を続けることはできないよ。
   (Without love, you can't keep a marriage going.)
2. 努力なくして成功なし。
   (Without effort, there is no success.)
3. 周囲の協力なくしては、このプロジェクトは完成しなかっただろう。
   (Without everyone's cooperation, this project would never have been completed.)
4. 信頼なくして、良い人間関係を築くことはできない。
   (Without trust, you cannot build good relationships.)
5. 犠牲なくして、大きな変革は成し遂げられない。
   (Without sacrifice, no great change can be achieved.)

**Common mistakes / key nuances:** Students often mix this up with the plainer なしに or ないで, not realizing なくして(は) is reserved for formal, almost aphoristic statements about indispensable conditions (often appearing in set phrases like 努力なくして成功なし). Also note the predicate at the end is nearly always negative-potential ("cannot/could not"), so a sentence ending in a plain affirmative verb is a red flag that this pattern was misapplied.
