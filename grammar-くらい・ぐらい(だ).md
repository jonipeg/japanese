# ～くらい／～ぐらい（だ） {#くらい・ぐらい（だ）}
#japanese-grammar
#grammar

**Kanji form:** ～くらい／～ぐらい（だ）

**Furigana form:** ～くらい／～ぐらい（だ）

**Meaning:** "To the extent that / so much that (as to reach this degree)" — illustrates the intensity of something by citing an extreme or representative example.

**Conjugation:**
- 動詞／い形容詞普通形 + くらい（だ）
- な形容詞 + な + くらい（だ）
- 名詞 + くらい（だ）

**Typical context:** Spoken and written, neutral-casual register — common in everyday conversation for emphasis.

**Similar grammar structures:**
- [**ほど**](grammar-ほど・ほどの・ほどだ.md) — nearly synonymous, "to the extent that," slightly more formal/written than くらい.
- [**まで**](grammar-まで(のことをして).md) — "to the point of (even doing X)," which emphasizes reaching an extreme action rather than a degree comparison.

**Opposite grammar structures:** No direct opposite.

**Example sentences:**
1. 恥ずかしくて死にたいくらいだった。
   (I was so embarrassed I felt like I wanted to die.)
2. 彼の料理はプロ並みと言えるくらいおいしい。
   (His cooking is delicious enough to be called professional-level.)
3. 声が聞こえないくらい、周りがうるさかった。
   (It was so noisy around us that you couldn't hear voices.)
4. 今日は歩けないくらい疲れている。
   (I'm so tired today that I can barely walk.)
5. 彼女は泣きたくなるくらい感動した。
   (She was moved to the point of almost crying.)

**Common mistakes / key nuances:** くらい and ぐらい are interchangeable in most casual contexts (ぐらい sounds slightly more casual), but don't confuse this degree-emphasis usage with the basic "approximately" usage of くらい (e.g., 三時間くらい = "about three hours") — context determines which meaning applies.
